== Description == 

Greyd.Suite is the comprehensive platform to scale up your WordPress business with great extensions to the Block and Site Editor as well as powerful features like website management, custom post types, headless features, forms and many more.
The Greyd.Plugin is the core plugin of the Greyd.Suite.

== Installation ==

* Download the Greyd Plugin from https://greyd.io
* Open your WordPress Admin Dashboard and go to 'Plugins'
* If you are in a multisite, you need to go to 'Network Admin > Plugins'
* Click 'add plugin' and then 'upload plugin'.
* Select the downloaded ZIP archive and upload it.
* Once uploaded you can now active the plugin.

== Setup and Configuration ==

* On activation, the wizard will start automatically and guide you through the setup that includes among others feature selection and (optional) child theme installation.
* Now the Greyd.Suite is ready to use. Via the 'Dashboard' you can access all important areas of Greyd.Suite.
* If you already have a 'license key', you can activate it under 'Greyd.Suite > Licenses'. You can also test Greyd.Suite without a license key for an unlimited period of time. Only for removing the watermark a valid license key is needed.
